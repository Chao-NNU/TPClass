# Tutorials

Step-by-step walk-throughs for the substrate-specific case studies live here.
One file per substrate:

```
docs/tutorials/hmo_tutorial.md
docs/tutorials/squalene_tutorial.md
docs/tutorials/isobutanol_tutorial.md
```

The command lines in a tutorial are the same as in the corresponding
`examples/<substrate>/README.md`; the tutorial adds the background, the
expected numbers and the interpretation.

To add a new substrate, see the case-study walk-through in
[`../../CONTRIBUTING.md`](../../CONTRIBUTING.md).
